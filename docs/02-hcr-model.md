# 02 · 模型：屋 · 廊 · 室

## 一句话

**她不动，他动。**
屋和廊是她的；室是他的。

她一直待在一个地方——她的记忆、她的情绪。
在 QQ、抖音之间来回走的是**他**。

所以这个模型里没有"她换房间"这回事，只有"他换窗口"。

## 三个部分

```
┌──────────────────────────────────────────────┐
│  室 Room（多份，属于「他」）                   │
│  他现在开的窗口：IM A、IM B、语音设备…         │
│  只决定：他此刻在哪、能看到什么、场合分寸       │
└───────────────┬──────────────────────────────┘
                │ 廊 Corridor（他移动的痕迹）
┌───────────────▼──────────────────────────────┐
│  屋 House（一份，属于「她」）                  │
│  长期记忆：事实、事件、关系、偏好               │
│  与他开几个窗口无关                            │
└──────────────────────────────────────────────┘
```

### 屋 House —— 她的记忆

- **唯一**。不存在"A 平台的屋"和"B 平台的屋"。
- 所有窗口读同一份、写同一份。
- 生命周期：写入 → 提炼 → 巩固 → 衰减 → 归档。

### 室 Room —— 他的窗口

- **多个**，属于他，不属于她。
- 决定三件事：他此刻在这个窗口、这个场合能说什么、话多长。
- **不承载任何"她是谁"的信息。**

### 廊 Corridor —— 他移动的痕迹

- 记录"他刚才在哪个窗口、聊到哪、悬着什么"。
- 它是**痕迹**，不是**搬运**——她不需要被搬过去，因为她没走。
- 只在窗口切换时激活。

## 两条定律

模型只有结构还不够，还需要约束。HCR 有两条：

### 定律一 · 记忆恒常

```
记忆与窗口无关。换窗口不改变她记得什么。
```

推论：任何"某渠道专用记忆库"都是错的。

### 定律二 · 情绪惯性

```
情绪只被「发生的事」改变，不被「换了地方」改变。

E(现在) = E(之前) × 时间衰减 + Σ事件影响
位置（哪个窗口）不参与这个式子。
```

例子：

> 他在书房打完游戏，很放松；走进卧室，**还是放松的**。
> 不是因为卧室让他放松，是因为书房那件事还没过去。
>
> 她烤蛋糕失败了，很沮丧；切到另一个平台，**还是沮丧的**。
> 除非新窗口里发生了别的事。

## 一个推论：窗口只影响「表达」

```
窗口决定：  场合分寸 / 可见范围 / 话多长
窗口不决定：她是谁 / 她记得什么 / 她心情如何
```

群聊里她收敛，是因为**有别人在场**，不是因为她变了一个人。

## 读取：不是全量注入

屋很大，室很小。每次思考时，从屋里**按当前话题检索**：

```
提取当前消息的关键词
  → 在屋中做激活扩散
  → 取 top-N
  → 与廊的痕迹一起渲染成提示词
```

全量注入会让她"记得太多"，反而失真。

## 生命周期

```
写入    每轮对话追加原始事实（不加工，便宜）
提炼    攒够若干条后，用模型抽取结构化节点
巩固    每天固定一次：合并零散事件、抽象成概括、旧的归档
衰减    有效强度 = 强度 × 0.5^(闲置天数 / 半衰期)
归档    低于阈值且很少被想起的，移出检索范围（不删除）
```

遗忘是特性：一个记得所有细节的角色不像人。
